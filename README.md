# MiraDaily

Daily reward calendar and streak system for Paper 1.21.11 / Java 21.

## Current release

**v0.1.0**

Direct download:
https://github.com/FiveSOCE/Mira-Daily/releases/download/v0.1.0/MiraDaily-0.1.0.jar

All releases:
https://github.com/FiveSOCE/Mira-Daily/releases

## Features

- 30-day configurable daily reward calendar
- Claim streaks
- Streak protection support
- Configurable command rewards
- Persistent player claim data
- PlaceholderAPI support
- Public Bukkit ServicesManager API

## Commands

- `/daily` - Open the daily rewards calendar
- `/daily claim` - Claim today's reward
- `/daily streak` - View your current streak

## Requirements

- Paper 1.21.11
- Java 21
- PlaceholderAPI optional

## Build

```bash
./gradlew build
```

Output: `build/libs/MiraDaily-0.1.0.jar`
